# Sistema de gestión de comunidades de vecinos

## 1. Descripción del proyecto

Aplicación multiplataforma destinada a facilitar la gestión y comunicación de una comunidad de vecinos, permitiendo centralizar la información, los usuarios, las incidencias y diferentes funcionalidades relacionadas con la administración de la comunidad.

El proyecto está compuesto por un backend encargado de gestionar la lógica de negocio y el acceso a los datos, y un frontend multiplataforma desde el que los usuarios podrán utilizar las diferentes funcionalidades de la aplicación.

## 2. Objetivo general

Desarrollar una aplicación para la gestión integral de comunidades de vecinos que permita centralizar las tareas administrativas y facilitar la comunicación entre los administradores y los vecinos.

## 3. Objetivos específicos

* Gestionar los usuarios pertenecientes a una comunidad.
* Diferenciar los permisos y funcionalidades disponibles para administradores y vecinos.
* Implementar un sistema de autenticación y autorización mediante JWT.
* Gestionar las diferentes funcionalidades relacionadas con la administración de la comunidad.
* Desplegar la aplicación para permitir su utilización fuera del entorno de desarrollo.

## 4. Tecnologías

### 4.1 Backend

* **Java 17:** lenguaje de programación utilizado para el desarrollo del backend.
* **Spring Boot 3:** framework utilizado para desarrollar la aplicación backend y la API REST.
* **Spring Security:** utilizado para gestionar la autenticación y autorización de los usuarios.
* **JWT (JSON Web Token):** utilizado para la autenticación mediante tokens.
* **Maven:** herramienta utilizada para la gestión de dependencias y construcción del proyecto.
* **PostgreSQL:** sistema de gestión de bases de datos utilizado para almacenar la información de la aplicación.

### 5.2 Frontend

* **Flutter:** framework utilizado para desarrollar la aplicación multiplataforma.
* **Dart:** lenguaje de programación utilizado en el desarrollo del frontend.
